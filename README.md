# Windows Server Labs

A collection of hands-on Windows Server administration projects, built and 
documented as part of self-directed, practical learning — covering Active 
Directory, Group Policy, file services, and related enterprise 
infrastructure and security concepts.

This repository is kept separate from my Linux/offensive-security work, 
and focuses specifically on Windows Server administration and 
enterprise-style infrastructure design.

## Projects

Each folder in this repository is a self-contained lab project with its 
own README covering setup, configuration, screenshots, and notes on issues 
encountered along the way — documented as real troubleshooting logs, not 
just clean final results.

## About

This repository will grow over time as new labs and scenarios are added.
